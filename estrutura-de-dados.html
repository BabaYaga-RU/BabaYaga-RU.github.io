Aula 1 – Introdução às Estruturas de Dados

Uma estrutura de dados é uma forma organizada de armazenar e gerenciar dados na memória para que possam ser usados de maneira eficiente. A escolha da estrutura certa impacta diretamente no desempenho do algoritmo.

  • Estruturas lineares: vetores, listas, pilhas, filas
  • Estruturas não-lineares: árvores, grafos, tabelas hash
  • Complexidade de tempo: notação Big-O mede o crescimento do tempo em função do tamanho n da entrada

1.1 JVM e Gerenciamento de Memória (Java)

A Java Virtual Machine (JVM) divide a memória em áreas distintas:

ÁreaO que armazena
Stack (Pilha de chamadas)Variáveis locais, parâmetros, referências de objetos, frames de métodos
HeapObjetos criados com new, arrays; gerenciado pelo Garbage Collector
MetaspaceMetadados de classes, métodos, campos (substituiu PermGen no Java 8+)
Registradores de PCEndereço da instrução atual por thread
Native Method StackChamadas a métodos nativos (C/C++)
Stack vs Heap: Variáveis primitivas (int, double) ficam na stack; objetos (String, arrays, instâncias de classe) ficam no Heap. A stack é LIFO e de acesso rápido. O Heap é maior mas mais lento (GC overhead).

Aula 2 – Vetores e Listas Ligadas

2.1 Vetores (Arrays)

Um vetor é uma coleção de elementos do mesmo tipo armazenados em posições de memória contíguas. O acesso é O(1) pelo índice.

// Java – array estático
int[] numeros = new int[5];
numeros[0] = 10;
numeros[4] = 50;

// Java – ArrayList (array dinâmico)
import java.util.ArrayList;
ArrayList<Integer> lista = new ArrayList<>();
lista.add(10);
lista.add(20);
lista.remove(0);      // remove por índice
System.out.println(lista.get(0)); // 20
OperaçãoArray estáticoArrayList
Acesso por índiceO(1)O(1)
Inserção no finalO(1) amortizadoO(1) amortizado
Inserção no meioO(n)O(n)
Remoção no meioO(n)O(n)
Busca linearO(n)O(n)
Quando usar vetor: Quando você precisa de acesso aleatório rápido e o tamanho é relativamente fixo. Prefira ArrayList em Java para flexibilidade.

2.2 Listas Ligadas (Linked Lists)

Uma lista ligada é composta por nós, cada um contendo um valor e um ponteiro para o próximo nó. Não requer memória contígua.

// Java – implementação de nó
class No {
    int valor;
    No proximo;
    No(int v) { valor = v; proximo = null; }
}

class ListaLigada {
    No cabeca;
    
    void inserirInicio(int v) {
        No novo = new No(v);
        novo.proximo = cabeca;
        cabeca = novo;
    }
    
    void inserirFim(int v) {
        No novo = new No(v);
        if (cabeca == null) { cabeca = novo; return; }
        No atual = cabeca;
        while (atual.proximo != null) atual = atual.proximo;
        atual.proximo = novo;
    }
    
    void imprimir() {
        No atual = cabeca;
        while (atual != null) {
            System.out.print(atual.valor + " -> ");
            atual = atual.proximo;
        }
        System.out.println("null");
    }
}
OperaçãoLista SimplesLista Dupla
Acesso por índiceO(n)O(n)
Inserção no inícioO(1)O(1)
Inserção no fimO(n) / O(1)*O(1)
Remoção por valorO(n)O(n)
* O(1) se mantiver ponteiro para o fim
Cuidado: Listas ligadas têm overhead de memória (armazenam ponteiro além do valor) e cache-miss mais frequente que arrays (memória não contígua).

Aula 3 – Pilhas e Filas

3.1 Pilhas (Stack) – LIFO

Uma pilha segue o princípio Last In, First Out: o último elemento inserido é o primeiro a ser removido. Analogia: pilha de pratos.

import java.util.Stack;

Stack<Integer> pilha = new Stack<>();
pilha.push(10);   // empilha
pilha.push(20);
pilha.push(30);

System.out.println(pilha.peek());  // 30 (topo, sem remover)
System.out.println(pilha.pop());   // 30 (remove)
System.out.println(pilha.isEmpty()); // false
System.out.println(pilha.size());    // 2

Implementação com Array:

class Pilha {
    int[] dados;
    int topo = -1;
    Pilha(int capacidade) { dados = new int[capacidade]; }
    
    void push(int v) {
        if (topo == dados.length - 1) throw new RuntimeException("Pilha cheia!");
        dados[++topo] = v;
    }
    void pop() {
        if (topo == -1) throw new RuntimeException("Pilha vazia!");
        return dados[topo--];
    }
    int peek() { return dados[topo]; }
    boolean isEmpty() { return topo == -1; }
}
Usos práticos de pilhas: histórico de navegação (voltar/avançar), undo/redo em editores, avaliação de expressões matemáticas (notação polonesa reversa), chamadas de funções recursivas na JVM, parsing de HTML/XML.

3.2 Filas (Queue) – FIFO

Uma fila segue o princípio First In, First Out: o primeiro elemento inserido é o primeiro a ser removido. Analogia: fila de banco.

import java.util.LinkedList;
import java.util.Queue;

Queue<String> fila = new LinkedList<>();
fila.offer("Alice");   // enfileira (preferível a add)
fila.offer("Bob");
fila.offer("Carlos");

System.out.println(fila.peek());   // "Alice" (frente, sem remover)
System.out.println(fila.poll());   // "Alice" (remove)
System.out.println(fila.size());   // 2

Fila Circular com Array:

class FilaCircular {
    int[] dados;
    int inicio = 0, fim = 0, tamanho = 0;
    FilaCircular(int cap) { dados = new int[cap]; }
    
    void enqueue(int v) {
        if (tamanho == dados.length) throw new RuntimeException("Fila cheia!");
        dados[fim] = v;
        fim = (fim + 1) % dados.length;
        tamanho++;
    }
    int dequeue() {
        if (tamanho == 0) throw new RuntimeException("Fila vazia!");
        int v = dados[inicio];
        inicio = (inicio + 1) % dados.length;
        tamanho--;
        return v;
    }
}
Usos práticos de filas: sistemas de impressão, escalonamento de processos no SO, BFS (busca em largura em grafos), buffers de comunicação, processamento de tarefas em background.

Aula 4 – Árvores

Uma árvore é uma estrutura hierárquica não-linear composta por nós conectados por arestas, sem ciclos.

  • Raiz: nó sem pai (único)
  • Folha: nó sem filhos
  • Altura: maior profundidade da raiz até uma folha
  • Grau: número de filhos de um nó

4.1 Árvore Binária de Busca (BST)

Propriedade fundamental: para cada nó, todos os valores na subárvore esquerda são menores, e na direita são maiores.

class No {
    int valor;
    No esq, dir;
    No(int v) { valor = v; }
}

class BST {
    No raiz;
    
    No inserir(No no, int v) {
        if (no == null) return new No(v);
        if (v < no.valor) no.esq = inserir(no.esq, v);
        else if (v > no.valor) no.dir = inserir(no.dir, v);
        return no;
    }
    
    // Em-ordem: visita esq → raiz → dir (resultado ordenado!)
    void emOrdem(No no) {
        if (no == null) return;
        emOrdem(no.esq);
        System.out.print(no.valor + " ");
        emOrdem(no.dir);
    }
    
    boolean buscar(No no, int v) {
        if (no == null) return false;
        if (v == no.valor) return true;
        return v < no.valor ? buscar(no.esq, v) : buscar(no.dir, v);
    }
}

InserçãoO(log n)O(n)
RemoçãoO(log n)O(n)

4.2 Árvore AVL (Auto-balanceada)

A Árvore AVL mantém o balanceamento automático: a diferença de altura entre subárvores esq e dir de qualquer nó é no máximo 1 (fator de balanceamento ∈ {-1, 0, 1}).

class NoAVL {
    int valor, altura;
    NoAVL esq, dir;
    NoAVL(int v) { valor = v; altura = 1; }
}

// Fator de balanceamento
int fb(NoAVL n) {
    if (n == null) return 0;
    return altura(n.esq) - altura(n.dir);
}

// Rotação simples à direita
NoAVL rotDir(NoAVL y) {
    NoAVL x = y.esq;
    NoAVL T2 = x.dir;
    x.dir = y;
    y.esq = T2;
    y.altura = Math.max(altura(y.esq), altura(y.dir)) + 1;
    x.altura = Math.max(altura(x.esq), altura(x.dir)) + 1;
    return x;
}
Rotações AVL: Quando o fator de balanceamento sai de [-1,1], aplica-se uma das 4 rotações: rotação direita (LL), rotação esquerda (RR), rotação dupla esquerda-direita (LR), rotação dupla direita-esquerda (RL).
