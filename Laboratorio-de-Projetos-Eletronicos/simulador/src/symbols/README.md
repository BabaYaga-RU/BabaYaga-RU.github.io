Standard LTspice symbol definitions (`.asy`) used by the analog canvas renderer.

The geometry and pin metadata are kept in the native text format and rendered as SVG at runtime.
Sources consulted:

- https://github.com/evenator/LTSpice-Libraries/tree/master/sym
- https://github.com/itstorque/ltspice-tikz/blob/main/voltage.asy
- https://analogdevicesinc.github.io/ltspice-reference/ai_ref/SCHEMATIC-REFERENCE.html
