Aula rápida: o que você precisa dominar

1. Componentes montam a tela

Um componente é uma função que retorna JSX. Ele representa uma parte da interface.

  • Começa com letra maiúscula: `App`, `Car`, `Combustao`.
  • Pode ser reutilizado várias vezes.
  • Pode chamar outros componentes dentro dele.

2. Estado guarda o que muda

Quando um valor precisa mudar na tela, ele deve ficar em estado com `useState`.

  • Número digitado em input.
  • Resultado de uma conta.
  • Lista de tarefas adicionadas pelo usuário.

3. Eventos executam ações

Eventos ligam a ação do usuário a uma função JavaScript.

  • `onClick` para botão.
  • `onChange` para digitação.
  • `onKeyDown` para detectar Enter.

Conceitos essenciais

React

React é uma biblioteca JavaScript para criar interfaces. A tela é dividida em componentes, que retornam JSX. 

function App() {
  return <h1>Olá, React</h1>;
}
  • `function App()` cria um componente chamado `App`.
  • `return` diz o que esse componente vai mostrar na tela.
  • `<h1>Olá, React</h1>` mostra um título grande no navegador.

Vite

Vite é a ferramenta que cria e roda o projeto durante o desenvolvimento. O comando mais comum é `npm run dev`. 

{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "lint": "eslint .",
    "preview": "vite preview"
  }
}
  • `dev` inicia o projeto para programar e testar no navegador.
  • `build` gera a versão final do site.
  • `lint` procura erros e problemas de padrão no código.

JSX

JSX parece HTML, mas é JavaScript. Por isso, expressões entram entre chaves: `{variavel}`, `{funcao()}`, `{condicao ? a : b}`. 

<h1>Resultado: {resultado}</h1>
<button onClick={somar}>Calcular</button>
  • `<h1>` cria um título na tela.
  • `Resultado:` é texto fixo.
  • `{resultado}` mostra o valor da variável ou estado chamado `resultado`.
  • `<button>Calcular</button>` cria um botão com o texto “Calcular”.
  • `onClick={somar}` significa: quando clicar no botão, execute a função `somar`.

Renderização inicial

O `index.html` tem uma div com `id="root"`. O `main.jsx` pega essa div e manda o React renderizar o componente principal. 

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <App />
  </StrictMode>
);
  • `document.getElementById('root')` pega a div principal do HTML.
  • `createRoot(...)` entrega essa div para o React controlar.
  • `render(<App />)` manda o React colocar o componente `App` na tela.

Componentes, props, import e export

Componente é uma função que retorna JSX

No React, componentes normalmente começam com letra maiúscula. Um componente pode ser importado e usado como se fosse uma tag HTML. 

import Car from './Car.jsx';

function App() {
  return (
    <div>
      <Car modelo="Fusca" />
      <Car modelo="Civic" />
      <Car modelo="Mustang" />
    </div>
  );
}
  • `import Car from './Car.jsx'` traz o componente `Car` de outro arquivo.
  • `<Car modelo="Fusca" />` usa o componente `Car` e envia a prop `modelo` com valor `"Fusca"`.
  • O mesmo componente é reutilizado três vezes, mudando só o valor da prop.

Ideia que cai muito

`App` é componente pai. `Car` é filho. Quando escrevemos `<Car modelo="Fusca" />`, o valor `"Fusca"` chega no filho dentro de `props.modelo`.

Props

Props são dados recebidos pelo componente. Elas vêm do componente pai e são usadas para personalizar o componente filho. 

function Car(props) {
  return <h1>Meu carro é {props.modelo}</h1>;
}
  • `props` é o objeto com os dados recebidos pelo componente.
  • `props.modelo` pega o valor enviado em `modelo="..."`.
  • Se receber `modelo="Civic"`, a tela mostra `Meu carro é Civic`.

Componente dentro de componente

`Combustao` recebe `tipomotor` e é usado dentro de `Car`. Isso mostra composição: montar uma interface juntando peças menores. 

function Combustao(props) {
  return <h1>{props.tipomotor}</h1>;
}

function Car(props) {
  return <Combustao tipomotor="ELÉTRICO" />;
}
  • `Combustao` é um componente menor.
  • `tipomotor="ELÉTRICO"` envia uma prop para esse componente.
  • `{props.tipomotor}` mostra o valor recebido dentro do `h1`.

Estado e eventos

`useState`

Estado é uma informação que o componente guarda e que, quando muda, faz a tela atualizar. `useState` devolve duas coisas: o valor atual e a função para mudar esse valor. 

const [motor, setMotor] = useState("COMBUSTÃO");

// motor: valor atual
// setMotor: função que altera o valor
  • `motor` começa valendo `"COMBUSTÃO"`.
  • `setMotor` é a função usada para trocar esse valor.
  • Quando `setMotor` é chamada, o React atualiza a tela automaticamente.

`onClick`

Evento de clique. Nesse padrão, o botão chama uma função que troca o estado de `"COMBUSTÃO"` para `"ELÉTRICO"`. 

<button onClick={() => setMotor("ELÉTRICO")}>
  Mudar para Elétrico
</button>
  • `onClick` espera uma função para executar no clique.
  • `() => ...` cria uma função curta, chamada apenas quando o botão for clicado.
  • `setMotor("ELÉTRICO")` muda o estado `motor` para `"ELÉTRICO"`.

Soma: três estados

Em uma soma com inputs, use um estado para cada número e outro para o resultado. O cálculo só fica correto quando o texto digitado é convertido com `Number`. 

const [numero1, setNumero1] = useState(0);
const [numero2, setNumero2] = useState(0);
const [resultado, setResultado] = useState(0);

function somar() {
  setResultado(numero1 + numero2);
}
  • `numero1` guarda o primeiro número digitado.
  • `numero2` guarda o segundo número digitado.
  • `resultado` guarda a resposta da soma.
  • `somar()` calcula `numero1 + numero2` e salva em `resultado`.

Atenção na prova

Valor de input vem como texto. Sem `Number`, `"2" + "3"` vira `"23"`, não `5`. 

onChange={(e) => {
  setNumero1(Number(e.target.value));
}}
  • `onChange` roda quando o usuário digita ou altera o input.
  • `e` é o evento da digitação.
  • `e.target.value` é o valor atual escrito no input.
  • `Number(...)` transforma esse texto em número.

Listas, formulários e arrays

Input controlado

Um input controlado recebe o valor do estado e atualiza esse estado a cada digitação. Assim, React sabe exatamente o que está escrito. 

const [input, setInput] = useState('');

<input
  type="text"
  value={input}
  onChange={e => setInput(e.target.value)}
/>
  • `input` é o estado que guarda o texto digitado.
  • `value={input}` faz o campo mostrar o valor salvo no estado.
  • `onChange` atualiza o estado toda vez que o usuário digita.
  • `placeholder` seria apenas uma dica visual; `value` é o valor real do campo.

Adicionar item sem alterar o array original

React prefere atualização imutável: cria-se um novo array com spread `...ts` e adiciona-se a nova tarefa no final. 

setTasks(ts => [
  ...ts,
  { id: Date.now(), title: trimmed }
]);
  • `ts` representa a lista atual de tarefas.
  • `...ts` copia todas as tarefas que já existiam.
  • `{ id: Date.now(), title: trimmed }` cria a nova tarefa.
  • `setTasks(...)` salva a nova lista no estado.

`map` para renderizar lista

`map` transforma cada tarefa em um elemento `li`. O `key` ajuda o React a identificar cada item. 

{tasks.map(t => (
  <li key={t.id}>
    {t.title}
  </li>
))}
  • `tasks.map(...)` percorre todas as tarefas.
  • Para cada tarefa `t`, o código cria um `<li>`.
  • `key={t.id}` dá uma identificação única para aquele item.
  • `{t.title}` mostra o texto da tarefa na tela.

`filter` para remover

`filter` cria um novo array mantendo apenas os itens cujo `id` é diferente do item removido. 

const remove = (id) => {
  setTasks(ts => ts.filter(t => t.id !== id));
};
  • `remove` recebe o `id` da tarefa que deve sair.
  • `filter` cria uma nova lista.
  • `t.id !== id` mantém apenas as tarefas com id diferente do removido.
  • `setTasks` atualiza a tela com a lista filtrada.

Renderização condicional

O operador ternário escolhe o que aparece na tela: uma mensagem se não houver tarefas, ou a lista se houver. 

{tasks.length === 0
  ? <p>Nenhuma tarefa adicionada.</p>
  : <ul>...</ul>
}
  • `tasks.length === 0` verifica se a lista está vazia.
  • Depois do `?` vem o que aparece se for verdadeiro.
  • Depois do `:` vem o que aparece se for falso.
  • Ou seja: sem tarefas mostra mensagem; com tarefas mostra a lista.

Evento de teclado

`onKeyDown` recebe o evento do teclado. Se a tecla for Enter, a função `add` é chamada. 

const onKey = (e) => {
  if (e.key === 'Enter') add();
};
  • `onKey` recebe o evento do teclado.
  • `e.key` informa qual tecla foi apertada.
  • Se a tecla for `Enter`, a função `add()` é executada.

CSS, estrutura e comandos

Importação de CSS

O CSS pode ser importado direto no JavaScript. `main.jsx` importa `index.css`; `App.jsx` importa `App.css`. 

import './index.css';
import './App.css';
  • `import './index.css'` carrega estilos gerais da aplicação.
  • `import './App.css'` carrega estilos usados pelo componente principal.
  • Sem esse import, o CSS pode existir no projeto, mas não será aplicado.

Variáveis CSS

No `index.css`, `:root` define variáveis reutilizáveis, como cores, fonte e sombra. 

:root {
  --text: #6b6375;
  --bg: #fff;
  --accent: #aa3bff;
}
  • `:root` representa o nível principal do CSS.
  • `--text`, `--bg` e `--accent` são variáveis CSS.
  • Depois dá para reutilizar com `color: var(--text)`.

Responsividade

`@media` aplica estilos diferentes conforme o tamanho da tela ou preferência do usuário. 

@media (max-width: 1024px) {
  h1 {
    font-size: 36px;
  }
}
  • `@media` cria uma regra para um tamanho específico de tela.
  • `max-width: 1024px` significa: aplique isso em telas até 1024px.
  • Nesse caso, o `h1` fica menor em telas menores.

Erros comuns em prova

Somar textos sem converter

O valor de input vem como string. Se fizer `"2" + "3"`, o resultado será `"23"`. Para soma matemática, use `Number(e.target.value)`.

Alterar array direto

Evite modificar o array original. Crie um novo array com spread, `map` ou `filter`, e passe esse novo valor para a função `set`.

Esquecer `key` em lista

Ao renderizar uma lista com `map`, cada item precisa de uma `key` única para o React atualizar a tela corretamente.

Treino para a prova

1. O que é um componente React?

É uma função, normalmente com nome iniciado por letra maiúscula, que retorna JSX para formar uma parte da interface.

2. Para que servem props?

Props servem para passar dados de um componente pai para um componente filho. Exemplo: `<Car modelo="Fusca" />` envia `modelo` para `props.modelo`.

3. O que `useState` retorna?

Retorna um par: o valor atual do estado e uma função para alterar esse valor.

4. Por que usar `Number(e.target.value)` em uma soma com input?

Porque o valor de um input chega como texto. `Number` converte para número e permite soma matemática.

5. Qual a diferença entre `map` e `filter` em uma lista?

`map` transforma cada tarefa em JSX para mostrar na tela. `filter` cria um novo array removendo ou mantendo itens de acordo com uma condição.

6. Por que cada item da lista tem `key`?

Para o React identificar cada item da lista de forma estável e atualizar a tela corretamente.

7. Como o React entra no HTML?

O `index.html` tem `<div id="root"></div>`. O `main.jsx` usa `createRoot(document.getElementById('root'))` e renderiza `<App />`.

8. Explique o fluxo de uma lista de tarefas em uma frase.

O usuário digita no input, o estado `input` muda, `add` cria uma tarefa em `tasks`, `map` exibe a lista e `remove` usa `filter` para apagar pelo `id`.

Última revisão de 2 minutos

React monta telas com componentes. Props passam dados. Estado guarda dados que mudam. Eventos disparam funções. Inputs usam `e.target.value`. Arrays aparecem na tela com `map`; remoção usa `filter`; adição usa spread.
