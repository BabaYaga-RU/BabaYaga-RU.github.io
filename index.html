Conceitos essenciais

React

React é uma biblioteca JavaScript para criar interfaces. A tela é dividida em componentes, que retornam JSX. 

function App() {
  return <h1>Olá, React</h1>;
}

Vite

Vite é a ferramenta que cria e roda o projeto durante o desenvolvimento. O comando mais comum é `npm run dev`. 

{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "lint": "eslint .",
    "preview": "vite preview"
  }
}

JSX

JSX parece HTML, mas é JavaScript. Por isso, expressões entram entre chaves: `{variavel}`, `{funcao()}`, `{condicao ? a : b}`. 

<h1>Resultado: {resultado}</h1>
<button onClick={somar}>Calcular</button>

Renderização inicial

O `index.html` tem uma div com `id="root"`. O `main.jsx` pega essa div e manda o React renderizar o componente principal. 

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <App />
  </StrictMode>
);

Componentes, props, import e export

Componente é uma função que retorna JSX

No React, componentes normalmente começam com letra maiúscula. O arquivo `Veiculo.jsx` exporta `Car`, e o `App.jsx` importa esse componente. 

import Car from './Veiculo.jsx';

function App() {
  return (
    <div>
      <Car modelo="Fusca" />
      <Car modelo="Civic" />
      <Car modelo="Mustang" />
    </div>
  );
}

Ideia que cai muito

`App` é componente pai. `Car` é filho. Quando escrevemos `<Car modelo="Fusca" />`, o valor `"Fusca"` chega no filho dentro de `props.modelo`.

Props

Props são dados recebidos pelo componente. Elas vêm do componente pai e são usadas para personalizar o componente filho. 

function Car(props) {
  return <h1>Meu carro é {props.modelo}</h1>;
}

Componente dentro de componente

`Combustao` recebe `tipomotor` e é usado dentro de `Car`. Isso mostra composição: montar uma interface juntando peças menores. 

function Combustao(props) {
  return <h1>{props.tipomotor}</h1>;
}

function Car(props) {
  return <Combustao tipomotor="ELÉTRICO" />;
}

Estado e eventos

`useState`

Estado é uma informação que o componente guarda e que, quando muda, faz a tela atualizar. `useState` devolve duas coisas: o valor atual e a função para mudar esse valor. 

const [motor, setMotor] = useState("COMBUSTÃO");

// motor: valor atual
// setMotor: função que altera o valor

`onClick`

Evento de clique. No exemplo do carro, o botão chama uma função que troca o estado de `"COMBUSTÃO"` para `"ELÉTRICO"`. 

<button onClick={() => setMotor("ELÉTRICO")}>
  Mudar para Elétrico
</button>

Calculadora: três estados

A calculadora tem um estado para cada número e outro para o resultado. O cálculo só aparece corretamente porque os inputs são convertidos com `Number`. 

const [numero1, setNumero1] = useState(0);
const [numero2, setNumero2] = useState(0);
const [resultado, setResultado] = useState(0);

function somar() {
  setResultado(numero1 + numero2);
}

Atenção na prova

Valor de input vem como texto. Sem `Number`, `"2" + "3"` vira `"23"`, não `5`. 

onChange={(e) => {
  setNumero1(Number(e.target.value));
}}

Listas, formulários e arrays

Input controlado

No `todolist`, o input é controlado porque o valor exibido vem do estado e toda digitação atualiza esse estado. 

const [input, setInput] = useState('');

<input
  type="text"
  value={input}
  onChange={e => setInput(e.target.value)}
/>

Adicionar item sem alterar o array original

React prefere atualização imutável: cria-se um novo array com spread `...ts` e adiciona-se a nova tarefa no final. 

setTasks(ts => [
  ...ts,
  { id: Date.now(), title: trimmed }
]);

`map` para renderizar lista

`map` transforma cada tarefa em um elemento `li`. O `key` ajuda o React a identificar cada item. 

{tasks.map(t => (
  <li key={t.id}>
    {t.title}
  </li>
))}

`filter` para remover

`filter` cria um novo array mantendo apenas os itens cujo `id` é diferente do item removido. 

const remove = (id) => {
  setTasks(ts => ts.filter(t => t.id !== id));
};

Renderização condicional

O operador ternário escolhe o que aparece na tela: uma mensagem se não houver tarefas, ou a lista se houver. 

{tasks.length === 0
  ? <p>Nenhuma tarefa adicionada.</p>
  : <ul>...</ul>
}

Evento de teclado

`onKeyDown` recebe o evento do teclado. Se a tecla for Enter, a função `add` é chamada. 

const onKey = (e) => {
  if (e.key === 'Enter') add();
};

CSS, estrutura e comandos

Importação de CSS

O CSS pode ser importado direto no JavaScript. `main.jsx` importa `index.css`; `App.jsx` importa `App.css`. 

import './index.css';
import './App.css';

Variáveis CSS

No `index.css`, `:root` define variáveis reutilizáveis, como cores, fonte e sombra. 

:root {
  --text: #6b6375;
  --bg: #fff;
  --accent: #aa3bff;
}

Responsividade

`@media` aplica estilos diferentes conforme o tamanho da tela ou preferência do usuário. 

@media (max-width: 1024px) {
  h1 {
    font-size: 36px;
  }
}

Treino para a prova

1. O que é um componente React?

É uma função, normalmente com nome iniciado por letra maiúscula, que retorna JSX para formar uma parte da interface.

2. Para que servem props?

Props servem para passar dados de um componente pai para um componente filho. Exemplo: `<Car modelo="Fusca" />` envia `modelo` para `props.modelo`.

3. O que `useState` retorna?

Retorna um par: o valor atual do estado e uma função para alterar esse valor.

4. Por que usar `Number(e.target.value)` na calculadora?

Porque o valor de um input chega como texto. `Number` converte para número e permite soma matemática.

5. Qual a diferença entre `map` e `filter` no todolist?

`map` transforma cada tarefa em JSX para mostrar na tela. `filter` cria um novo array removendo ou mantendo itens de acordo com uma condição.

6. Por que cada item da lista tem `key`?

Para o React identificar cada item da lista de forma estável e atualizar a tela corretamente.

7. Como o React entra no HTML?

O `index.html` tem `<div id="root"></div>`. O `main.jsx` usa `createRoot(document.getElementById('root'))` e renderiza `<App />`.

8. Explique o fluxo do todolist em uma frase.

O usuário digita no input, o estado `input` muda, `add` cria uma tarefa em `tasks`, `map` exibe a lista e `remove` usa `filter` para apagar pelo `id`.

Última revisão de 2 minutos

React monta telas com componentes. Props passam dados. Estado guarda dados que mudam. Eventos disparam funções. Inputs usam `e.target.value`. Arrays aparecem na tela com `map`; remoção usa `filter`; adição usa spread.
