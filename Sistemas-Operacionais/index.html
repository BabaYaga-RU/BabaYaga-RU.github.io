Questões essenciais

O sistema em movimento

Associe cada mecanismo à responsabilidade correta do sistema operacional.

01. Copiar arquivo no Linux

Qual comando copia um arquivo para outro caminho?

Resposta: cp /dir/arquivo1 /dir/arquivo2.
cd muda de diretório, root identifica o superusuário e mkdir cria diretórios.

02. Licença do Linux

Como o Linux é distribuído?

Resposta: Gratuito e com código-fonte aberto.
Isso permite estudar e modificar o código. Não é software pago de código fechado nem gratuito com fonte fechada.

03. Kernel

Qual componente cria a plataforma comum para os programas?

Resposta: Kernel.
O kernel gerencia hardware e recursos. Shell é a interface de comandos; bootstrap inicia o sistema; middleware integra aplicações.

04. Função do sistema operacional

Qual alternativa descreve corretamente o sistema operacional?

Resposta: Gerenciar componentes de hardware e fornecer serviços aos programas.
Ele não existe apenas para cálculos, armazenamento ou criação de jogos; sua função é intermediar recursos e aplicações.

05. Sistema operacional multitarefa

O que significa um sistema ser multitarefa?

Resposta: Permitir a execução de mais de um programa ao mesmo tempo.
O sistema alterna e gerencia processos; não limita a um programa nem significa necessariamente uma quantidade fixa de cinco processos.

06. Multiprogramação

O que a multiprogramação permite?

Resposta: Manter vários programas em execução concorrente.
Ela aproveita melhor a CPU enquanto um processo espera I/O. Não é sinônimo de apenas executar um programa.

07. Processo

Qual definição corresponde a processo?

Resposta: Um programa em execução.
Programa é o código armazenado; processo é a instância ativa, com estado e recursos. Thread é uma unidade de execução dentro do processo.

08. Instância separada

O que é um processo?

Resposta: Uma instância separada de execução criada para executar um programa.
Ele possui espaço e estado próprios, ao contrário de uma simples função ou de todos os processos independentes do sistema.

09. Criação de processos

Considerando o código do simulado com fork(), quantos processos e threads são criados?

Resposta: 8 processos e 8 threads.
Cada fork duplica o fluxo de execução; ao final, cada processo possui sua thread principal.

10. Escalonamento

Qual é a principal função de um algoritmo de escalonamento?

Resposta: Decidir quais processos prontos devem ser alocados à CPU.
O escalonador não executa o processo nem distribui memória diretamente; ele escolhe a próxima oportunidade de uso da CPU.
