1.3 Inferência Estatística e Intervalos de Confiança

Um intervalo de confiança (IC) de 95% para a média é:

IC = x̄ ± zα/2 · (σ/√n)

Para amostras pequenas (n < 30) ou σ desconhecida, usa-se distribuição t de Student.

import numpy as np
import scipy.stats as stats

amostra = [23.5, 24.1, 22.8, 25.3, 23.9, 24.7, 22.1, 25.8]
n = len(amostra)
media = np.mean(amostra)
sem = stats.sem(amostra)  # erro padrão da média

# IC 95% com t de Student
ic = stats.t.interval(0.95, df=n-1, loc=media, scale=sem)
print(f"Média: {media:.2f}")
print(f"IC 95%: [{ic[0]:.2f}, {ic[1]:.2f}]")

# Teste t de uma amostra (H0: média == 24)
t_stat, p_val = stats.ttest_1samp(amostra, 24)
print(f"t={t_stat:.3f}, p={p_val:.4f}")

1.4 Conteúdo incorporado dos slides: interpretação estatística

Escolha e interpretação das medidas

  • Média: representa bem dados aproximadamente simétricos, mas é sensível a extremos.
  • Mediana: divide os dados ordenados e é robusta a outliers.
  • Moda: identifica o valor mais frequente e funciona também para categorias.
  • Amplitude: máximo menos mínimo; é simples, porém muito sensível a um único outlier.
  • Coeficiente de variação: CV = desvio / média × 100%; compara dispersões relativas entre escalas diferentes.

Para amostras, NumPy deve usar ddof=1 em np.var e np.std, dividindo por n − 1. Sem esse ajuste, calcula-se a medida populacional.

Quartis, boxplot e outliers

Q1, Q2 e Q3 deixam, respectivamente, 25%, 50% e 75% dos dados abaixo deles. O intervalo interquartil é IQR = Q3 − Q1. Um critério comum marca como outlier valores abaixo de Q1 − 1,5·IQR ou acima de Q3 + 1,5·IQR.

Na simulação, gráficos ajudam a identificar distribuição, instabilidade, picos e cenários extremos. Sistemas com a mesma média podem ter comportamentos muito diferentes quando seus desvios e CVs diferem.

Poisson e eventos por intervalo

A distribuição de Poisson modela o número de ocorrências independentes em um intervalo fixo, com taxa média constante λ. Nela, média e variância teóricas são iguais a λ. Exemplo: número de requisições recebidas por minuto.

Inferência, testes e interpretação correta

TermoSignificado
População / amostraTodo o conjunto de interesse / subconjunto observado
Parâmetro / estatísticaMedida da população / medida calculada da amostra
Erro tipo IRejeitar H₀ quando H₀ é verdadeira
Erro tipo IINão rejeitar H₀ quando H₀ é falsa

Em um teste com α = 0,05, rejeita-se H₀ quando p < 0,05. Quando p ≥ 0,05, a conclusão correta é não há evidência suficiente para rejeitar H₀, e não “H₀ foi provada”.

A distribuição t de Student é apropriada para inferir médias quando a variância populacional é desconhecida, especialmente com amostras pequenas. Suas caudas mais pesadas refletem maior incerteza.

Intervalo de confiança: dizer “95% de confiança” descreve o procedimento que gera intervalos. O parâmetro populacional é fixo; não se deve afirmar que ele tem 95% de chance de estar em um intervalo já calculado.

2. Simulação de Sistemas Computacionais

2.1 Conceitos Fundamentais

A simulação é a imitação computacional do comportamento de um sistema real ao longo do tempo, usada quando o sistema real é muito caro, perigoso ou complexo para experimentar diretamente.

def integrar_mc(f, a, b, n=100000):
    x = np.random.uniform(a, b, n)
    return (b - a) * np.mean(f(x))

resultado = integrar_mc(lambda x: np.exp(-x**2), 0, 1)

2.3 Simulação por Eventos Discretos (DES)

O tempo avança de evento em evento (não continuamente). A lista de eventos futuros (FEL) mantém os próximos eventos ordenados por tempo.

import heapq
import numpy as np

class SimuladorFila:
    def __init__(self, taxa_chegada, taxa_servico, n_servidores=1):
        self.la = taxa_chegada    # λ (chegadas/unidade de tempo)
        self.mu = taxa_servico    # μ (atendimentos/unidade de tempo)
        self.c = n_servidores
        self.fila = []            # lista de espera
        self.servidores = 0       # servidores ocupados
        self.eventos = []         # heap de (tempo, tipo)
        self.tempo = 0
        self.estatisticas = {
            'total_chegadas': 0, 'total_servicos': 0,
            'soma_espera': 0, 'soma_sistema': 0
        }
    
    def agendar(self, tempo, tipo, dados=None):
        heapq.heappush(self.eventos, (tempo, tipo, dados))
    
    def proximo_evento(self):
        return heapq.heappop(self.eventos)
    
    def chegada(self, tempo_chegada):
        self.estatisticas['total_chegadas'] += 1
        if self.servidores < self.c:
            self.servidores += 1
            tempo_servico = np.random.exponential(1/self.mu)
            self.agendar(self.tempo + tempo_servico, 'saida', self.tempo)
            self.estatisticas['soma_espera'] += 0
        else:
            self.fila.append(self.tempo)
        
        # próxima chegada
        inter_chegada = np.random.exponential(1/self.la)
        self.agendar(self.tempo + inter_chegada, 'chegada', None)
    
    def saida(self, tempo_entrada_servico):
        self.estatisticas['total_servicos'] += 1
        self.estatisticas['soma_sistema'] += (self.tempo - tempo_entrada_servico)
        if self.fila:
            t_entrada = self.fila.pop(0)
            espera = self.tempo - t_entrada
            self.estatisticas['soma_espera'] += espera
            tempo_servico = np.random.exponential(1/self.mu)
            self.agendar(self.tempo + tempo_servico, 'saida', self.tempo)
        else:
            self.servidores -= 1
    
    def simular(self, duracao):
        self.agendar(np.random.exponential(1/self.la), 'chegada', None)
        while self.eventos:
            tempo, tipo, dados = self.proximo_evento()
            if tempo > duracao:
                break
            self.tempo = tempo
            if tipo == 'chegada':
                self.chegada(dados)
            elif tipo == 'saida':
                self.saida(dados)
        return self.estatisticas

Um modelo útil não tenta copiar tudo. Ele responde uma pergunta específica com o nível de abstração necessário, sem complexidade que não altera a decisão.

Modelo analítico versus simulação

Modelo analíticoModelo de simulação

A simulação permite testar falhas, picos e decisões sem riscos reais, mas depende da qualidade dos dados, pode exigir muito tempo de modelagem e não garante encontrar a solução ótima.

Metodologia rigorosa

  1. Formular problema, objetivo, escopo e métricas.
  2. Coletar dados e caracterizar distribuições.
  3. Construir o modelo conceitual e implementá-lo.
  4. Verificar: confirmar que o programa implementa corretamente o modelo.
  5. Validar: confirmar que o modelo representa adequadamente o sistema real.
  6. Experimentar cenários e analisar resultados estatisticamente.
Diferença cobrada: verificação pergunta “construímos o modelo corretamente?”; validação pergunta “construímos o modelo correto para representar a realidade?”.

3. Teoria das Filas

A Notação de Kendall descreve sistemas de filas: A/S/c/K/N/D

  • A: distribuição das chegadas (M=exponencial/Markoviana, D=determinística, G=geral)
  • S: distribuição do serviço
  • c: número de servidores
  • K: capacidade do sistema (padrão: ∞)
  • N: tamanho da população (padrão: ∞)
  • D: disciplina da fila (FCFS, LCFS, SIRO, prioridade)

3.1 Modelo M/M/1

Chegadas e serviços exponenciais, 1 servidor, capacidade infinita.

MétricaFórmulaSignificado
ρ (utilização)λ/μ — deve ser < 1Fração do tempo que o servidor está ocupado
Lsρ/(1−ρ)Número médio de clientes no sistema
Lqρ²/(1−ρ)Número médio na fila (aguardando)
Ws1/(μ−λ)Tempo médio no sistema
Wqλ/(μ(μ−λ))Tempo médio de espera na fila
def metricas_mm1(lam, mu):
    """
    lam: taxa de chegada (clientes/hora)
    mu:  taxa de serviço (clientes/hora)
    """
    assert lam < mu, "Sistema instável: λ deve ser < μ"
    rho = lam / mu
    Ls = rho / (1 - rho)
    Lq = rho**2 / (1 - rho)
    Ws = 1 / (mu - lam)
    Wq = lam / (mu * (mu - lam))
    
    print(f"ρ (utilização):     {rho:.1%}")
    print(f"Ls (no sistema):    {Ls:.3f} clientes")
    print(f"Lq (na fila):       {Lq:.3f} clientes")
    print(f"Ws (tempo sistema): {Ws*60:.1f} minutos")
    print(f"Wq (tempo espera):  {Wq*60:.1f} minutos")

# Exemplo: padaria com 20 chegadas/hora, atende 30/hora
metricas_mm1(20, 30)

3.2 Modelo M/M/c

Chegadas e serviços exponenciais, c servidores em paralelo.

import math

def metricas_mmc(lam, mu, c):
    rho = lam / (c * mu)  # utilização por servidor
    assert rho < 1, "Sistema instável"
    
    r = lam / mu  # intensidade de tráfego total
    
    # Probabilidade de sistema vazio (P0)
    soma = sum((r**n) / math.factorial(n) for n in range(c))
    soma += (r**c) / (math.factorial(c) * (1 - rho))
    P0 = 1 / soma
    
    # Probabilidade de esperar (Erlang C)
    Pc = (r**c / (math.factorial(c) * (1 - rho))) * P0
    
    Lq = Pc * rho / (1 - rho)
    Wq = Lq / lam
    Ws = Wq + 1/mu
    Ls = lam * Ws
    
    print(f"Servidores: {c}, ρ/servidor: {rho:.1%}")
    print(f"P(esperar): {Pc:.1%}")
    print(f"Lq: {Lq:.3f} | Ls: {Ls:.3f}")
    print(f"Wq: {Wq*60:.2f} min | Ws: {Ws*60:.2f} min")

metricas_mmc(lam=30, mu=20, c=2)  # 30 chegadas/h, cada servidor atende 20/h
Lei de Little: L = λ · W (válida para qualquer sistema de filas em equilíbrio). Conecta o número médio de clientes (L), a taxa de chegada (λ) e o tempo médio no sistema (W).

3.3 Simulação Completa em Python com SimPy

import simpy
import numpy as np
import statistics

TAXA_CHEGADA  = 3.0   # clientes por minuto
TAXA_SERVICO  = 4.0   # atendimentos por minuto
N_SERVIDORES  = 1
DURACAO_SIM   = 480   # 8 horas (minutos)

tempos_espera = []

def cliente(env, nome, servidor):
    chegada = env.now
    with servidor.request() as req:
        yield req
        espera = env.now - chegada
        tempos_espera.append(espera)
        tempo_servico = np.random.exponential(1/TAXA_SERVICO)
        yield env.timeout(tempo_servico)

def gerador_clientes(env, servidor):
    i = 0
    while True:
        yield env.timeout(np.random.exponential(1/TAXA_CHEGADA))
        i += 1
        env.process(cliente(env, f"C{i}", servidor))

# Executar simulação
np.random.seed(42)
env = simpy.Environment()
servidor = simpy.Resource(env, capacity=N_SERVIDORES)
env.process(gerador_clientes(env, servidor))
env.run(until=DURACAO_SIM)

print(f"Clientes atendidos:  {len(tempos_espera)}")
print(f"Espera média:        {statistics.mean(tempos_espera):.3f} min")
print(f"Espera mediana:      {statistics.median(tempos_espera):.3f} min")
print(f"Espera máxima:       {max(tempos_espera):.3f} min")

# Comparar com M/M/1 teórico
rho = TAXA_CHEGADA / TAXA_SERVICO
Wq_teorico = TAXA_CHEGADA / (TAXA_SERVICO * (TAXA_SERVICO - TAXA_CHEGADA))
print(f"Wq teórico M/M/1:    {Wq_teorico:.3f} min")

3.4 Conteúdo incorporado dos slides: análise completa de filas

Elementos do sistema

  • População/fonte: conjunto finito ou infinito de clientes potenciais.
  • Processo de chegada: define os tempos entre chegadas.
  • Fila/buffer: armazena quem aguarda e pode ter capacidade finita.
  • Disciplina: FIFO, LIFO, prioridades ou outra regra de atendimento.
  • Servidores: recursos que executam o serviço.

Em computação, clientes podem ser processos aguardando CPU, pacotes em roteadores, consultas de banco, requisições web ou tarefas destinadas a GPUs.

Notação de Kendall em exemplos

ModeloLeitura
M/M/1Chegadas e serviços markovianos, um servidor; demais campos assumidos infinitos/FIFO
M/D/3/10Chegadas markovianas, serviço determinístico, três servidores, capacidade total 10
M/G/4Chegadas markovianas, serviço com distribuição geral, quatro servidores

A distribuição exponencial é “sem memória”: dado que o evento ainda não ocorreu, o tempo já esperado não altera a distribuição do tempo restante.

Métricas e estabilidade

No M/M/1, a estabilidade exige λ < μ e a utilização é ρ = λ/μ. Além de L, Lq, W e Wq, os slides destacam:

  • P₀ = 1 − ρ: probabilidade de o sistema estar vazio;
  • Pₙ = (1 − ρ)ρⁿ: probabilidade de haver exatamente n clientes;
  • quando ρ se aproxima de 1, filas e tempos de espera crescem de forma não linear.

No M/M/c, a condição é ρ = λ/(cμ) < 1. Erlang C calcula a probabilidade de uma chegada precisar esperar.

Uso conjunto: os modelos analíticos M/M/1 e M/M/c servem como referência para verificar e calibrar uma simulação. A simulação é necessária quando hipóteses como exponencialidade, capacidade infinita ou servidores idênticos não representam o sistema real.

4. Flashcards de revisão

Clique em um card para conferir a resposta. Fechado, ele mostra apenas o tópico; aberto, cresce conforme o conteúdo.

EstatísticaQuando preferir mediana em vez de média?
Resposta

Quando os dados possuem outliers ou forte assimetria. A mediana depende da posição dos valores ordenados e sofre menos influência de extremos.

DispersãoQual é a relação entre variância e desvio padrão?
Resposta

A variância mede o espalhamento quadrático. O desvio padrão é sua raiz quadrada e volta para a mesma unidade dos dados.

ComparaçãoPara que serve o coeficiente de variação?
Resposta

CV = desvio padrão / média × 100%. Ele compara a dispersão relativa de conjuntos medidos em escalas ou unidades diferentes.

InferênciaComo interpretar um p-valor?
Resposta

É a probabilidade de observar um resultado tão extremo quanto o obtido, assumindo H₀ verdadeira. Se p < α, rejeita-se H₀; caso contrário, apenas não há evidência suficiente para rejeitá-la.

InferênciaO que informa um intervalo de confiança?
Resposta

Ele apresenta uma faixa plausível para o parâmetro estimado. Aumentar a amostra normalmente reduz a margem de erro e estreita o intervalo.

DistribuiçõesPoisson e exponencial modelam o quê?
Resposta

Poisson modela a quantidade de eventos em um intervalo. Exponencial modela o tempo entre eventos quando eles seguem um processo de Poisson.

ModelagemQual é a diferença entre modelo e simulação?
Resposta

O modelo é uma representação simplificada do sistema real. A simulação executa esse modelo ao longo do tempo ou de cenários para analisar seu comportamento.

ClassificaçãoDeterminístico ou estocástico?
Resposta

Um modelo determinístico sempre produz o mesmo resultado para as mesmas entradas. Um modelo estocástico inclui variáveis aleatórias e pode produzir resultados diferentes.

ClassificaçãoSimulação contínua ou por eventos discretos?
Resposta

Na contínua, o estado varia continuamente no tempo. Em eventos discretos, o estado muda apenas quando eventos específicos ocorrem.

MétodoComo funciona o método de Monte Carlo?
Resposta

Executa muitas amostragens aleatórias para estimar probabilidades, riscos ou resultados difíceis de calcular diretamente. A precisão melhora com mais repetições.

Eventos discretosQuais elementos formam uma DES?
Resposta

Entidades, recursos, filas, variáveis de estado, relógio de simulação e uma lista de eventos futuros que determina a próxima mudança.

QualidadeVerificação e validação são iguais?
Resposta

Não. Verificação pergunta se o modelo foi implementado corretamente. Validação pergunta se o modelo representa adequadamente o sistema real para o objetivo definido.

ExperimentoPor que executar várias replicações?
Resposta

Uma única execução estocástica pode ser atípica. Replicações independentes permitem estimar médias, variabilidade e intervalos de confiança.

ExperimentoPara que serve o período de aquecimento?
Resposta

Serve para reduzir o viés causado pelo estado inicial artificial, descartando observações até que o sistema se aproxime do regime estável.

FilasO que descreve a notação de Kendall?
Resposta

A/S/c/K/N/D descreve distribuições de chegada e serviço, quantidade de servidores, capacidade, população e disciplina da fila.

M/M/1Qual é a condição de estabilidade?
Resposta

É necessário λ < μ, portanto ρ = λ/μ < 1. Se a chegada média alcança ou supera o atendimento, a fila tende a crescer sem limite.

UtilizaçãoO que significa ρ próximo de 1?
Resposta

O recurso está ocupado quase todo o tempo. Mesmo antes de atingir 100%, pequenas variações podem causar crescimento não linear da fila e da espera.

Lei de LittleComo relacionar quantidade, taxa e tempo?
Resposta

L = λW. Em equilíbrio, o número médio de clientes no sistema é igual à taxa média de chegada multiplicada pelo tempo médio no sistema.

MétricasQual é a diferença entre L, Lq, W e Wq?
Resposta

L é a quantidade média no sistema; Lq, apenas na fila; W é o tempo médio total no sistema; Wq, apenas o tempo médio aguardando atendimento.

M/M/cComo muda a utilização com vários servidores?
Resposta

Com c servidores idênticos, ρ = λ/(cμ). A estabilidade ainda exige ρ < 1, e Erlang C calcula a probabilidade de uma chegada precisar esperar.
