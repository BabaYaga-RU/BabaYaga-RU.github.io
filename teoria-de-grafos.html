Aula 1 – Introdução à Teoria de Grafos

Um grafo G = (V, E) é uma estrutura matemática composta por um conjunto de vértices (V) e um conjunto de arestas (E) que conectam pares de vértices.

  • Vértice (nó): entidade do problema (cidade, pessoa, processo)
  • Aresta: relacionamento entre dois vértices (estrada, amizade, dependência)
  • Grau de um vértice: número de arestas incidentes nele
Aplicações reais: redes de computadores, rotas de GPS (menor caminho), redes sociais (análise de influência), compiladores (grafo de dependências), bioinformática (redes proteicas).

1.1 Problema das Pontes de Königsberg (1736)

Euler resolveu o problema histórico: "É possível percorrer todas as 7 pontes de Königsberg exatamente uma vez e voltar ao ponto de partida?"

Euler provou que não, modelando as margens como vértices e as pontes como arestas. Sua conclusão: um percurso euleriano (que passa por todas as arestas exatamente uma vez) só existe se o grafo tiver exatamente 0 ou 2 vértices com grau ímpar.

Este problema deu origem à Teoria de Grafos. O grafo resultante tinha 4 vértices e 7 arestas, com todos os vértices de grau ímpar (3 ou 5), impossibilitando o circuito.

Aula 2 – Representação Computacional de Grafos

2.1 Matriz de Adjacência

Uma matriz n×n onde A[i][j] = 1 (ou peso) se existe aresta entre i e j, 0 caso contrário.

// Java – Grafo com Matriz de Adjacência
class GrafoMatriz {
    int[][] adj;
    int n;
    
    GrafoMatriz(int n) {
        this.n = n;
        adj = new int[n][n];
    }
    
    void addAresta(int u, int v) {    // grafo não-dirigido
        adj[u][v] = 1;
        adj[v][u] = 1;
    }
    
    void addArestaPeso(int u, int v, int w) {
        adj[u][v] = w;
        adj[v][u] = w;
    }
    
    boolean existeAresta(int u, int v) {
        return adj[u][v] != 0;
    }
    
    void imprimir() {
        for (int[] linha : adj) {
            for (int val : linha) System.out.printf("%3d", val);
            System.out.println();
        }
    }
}

2.2 Lista de Adjacência

Cada vértice possui uma lista de seus vizinhos. Mais eficiente para grafos esparsos.

import java.util.*;

class GrafoLista {
    int n;
    List<List<Integer>> adj;
    
    GrafoLista(int n) {
        this.n = n;
        adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
    }
    
    void addAresta(int u, int v) {
        adj.get(u).add(v);
        adj.get(v).add(u);   // remover para dígrafo
    }
    
    List<Integer> vizinhos(int u) {
        return adj.get(u);
    }
}

// Versão com pesos (aresta como objeto)
class Aresta {
    int destino, peso;
    Aresta(int d, int p) { destino = d; peso = p; }
}
AspectoLista de Adjacência
EspaçoO(V + E) — eficiente para grafos esparsos
Verificar arestaO(grau do vértice)
Listar vizinhosO(grau do vértice)
Ideal paraGrafos esparsos (poucas arestas)

Aula 3 – Algoritmos de Percurso

3.1 BFS – Busca em Largura (Breadth-First Search)

Visita os vértices camada por camada, explorando todos os vizinhos antes de ir mais fundo. Usa uma fila.

void bfs(GrafoLista g, int inicio) {
    boolean[] visitado = new boolean[g.n];
    Queue<Integer> fila = new LinkedList<>();
    
    visitado[inicio] = true;
    fila.offer(inicio);
    
    while (!fila.isEmpty()) {
        int v = fila.poll();
        System.out.print(v + " ");
        
        for (int vizinho : g.vizinhos(v)) {
            if (!visitado[vizinho]) {
                visitado[vizinho] = true;
                fila.offer(vizinho);
            }
        }
    }
}
Usos do BFS: menor caminho em grafos não-ponderados, verificar se grafo é bipartido, nível de separação em redes sociais, algoritmos de roteamento em redes.
ComplexidadeValor
TempoO(V + E)
EspaçoO(V) — tamanho da fila

3.2 DFS – Busca em Profundidade (Depth-First Search)

Explora o mais fundo possível antes de voltar. Pode ser implementada com pilha ou recursão.

// DFS recursiva
void dfs(GrafoLista g, int v, boolean[] visitado) {
    visitado[v] = true;
    System.out.print(v + " ");
    
    for (int vizinho : g.vizinhos(v)) {
        if (!visitado[vizinho]) {
            dfs(g, vizinho, visitado);
        }
    }
}

// Chamada
boolean[] vis = new boolean[g.n];
dfs(g, 0, vis);  // inicia no vértice 0

// DFS iterativa com pilha
void dfsIterativa(GrafoLista g, int inicio) {
    boolean[] visitado = new boolean[g.n];
    Stack<Integer> pilha = new Stack<>();
    pilha.push(inicio);
    
    while (!pilha.isEmpty()) {
        int v = pilha.pop();
        if (visitado[v]) continue;
        visitado[v] = true;
        System.out.print(v + " ");
        for (int viz : g.vizinhos(v))
            if (!visitado[viz]) pilha.push(viz);
    }
}
Usos do DFS: detecção de ciclos, ordenação topológica, componentes fortemente conexos (algoritmo de Tarjan/Kosaraju), labirintos, resolução de puzzles.

Aula 4 – Caminhos Mínimos e Ciclos

4.1 Algoritmo de Dijkstra

Encontra o menor caminho de um vértice fonte a todos os outros em grafos com pesos não-negativos.

import java.util.*;

void dijkstra(int[][] grafo, int src, int n) {
    int[] dist = new int[n];
    boolean[] visitado = new boolean[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;
    
    // PriorityQueue: {distancia, vertice}
    PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
    pq.offer(new int[]{0, src});
    
    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int d = curr[0], u = curr[1];
        if (visitado[u]) continue;
        visitado[u] = true;
        
        for (int v = 0; v < n; v++) {
            if (grafo[u][v] != 0 && dist[u] + grafo[u][v] < dist[v]) {
                dist[v] = dist[u] + grafo[u][v];
                pq.offer(new int[]{dist[v], v});
            }
        }
    }
    // dist[] contém as menores distâncias de src a cada vértice
}
ComplexidadeCom arrayCom fila de prioridade
TempoO(V²)O((V+E) log V)
EspaçoO(V)O(V+E)
Limitação: Dijkstra não funciona com pesos negativos. Para isso, use o algoritmo de Bellman-Ford O(VE).

Aula 5 – Árvores Geradoras Mínimas

Uma Árvore Geradora Mínima (AGM / MST) de um grafo conexo ponderado é uma subárvore que conecta todos os vértices com o menor custo total de arestas possível.

Aplicações: redes de telecomunicações, distribuição elétrica, projeto de circuitos.

5.1 Algoritmo de Kruskal

Estratégia gulosa: ordena arestas por peso crescente e adiciona cada aresta se não forma ciclo (Union-Find).

class KruskalMST {
    int[] pai, rank;
    
    int find(int x) {
        if (pai[x] != x) pai[x] = find(pai[x]);  // path compression
        return pai[x];
    }
    
    void union(int x, int y) {
        int px = find(x), py = find(y);
        if (rank[px] < rank[py]) pai[px] = py;
        else if (rank[px] > rank[py]) pai[py] = px;
        else { pai[py] = px; rank[px]++; }
    }
    
    int[][] kruskal(int n, int[][] arestas) {
        // arestas[i] = {peso, u, v}
        Arrays.sort(arestas, (a,b) -> a[0]-b[0]);
        pai = new int[n]; rank = new int[n];
        for (int i = 0; i < n; i++) pai[i] = i;
        
        List<int[]> mst = new ArrayList<>();
        for (int[] e : arestas) {
            if (find(e[1]) != find(e[2])) {
                union(e[1], e[2]);
                mst.add(e);
                if (mst.size() == n-1) break;
            }
        }
        return mst.toArray(new int[0][]);
    }
}

Complexidade: O(E log E) para ordenar + O(E α(V)) para Union-Find ≈ O(E log E)

5.2 Algoritmo de Prim

Cresce a árvore a partir de um vértice inicial, sempre adicionando a aresta de menor peso que conecta um novo vértice.

void prim(int[][] grafo, int n) {
    int[] chave = new int[n];      // peso mínimo para entrar na MST
    boolean[] inMST = new boolean[n];
    int[] pai = new int[n];
    
    Arrays.fill(chave, Integer.MAX_VALUE);
    chave[0] = 0; pai[0] = -1;
    
    for (int i = 0; i < n-1; i++) {
        // encontra vértice com menor chave não incluído
        int u = -1;
        for (int v = 0; v < n; v++)
            if (!inMST[v] && (u == -1 || chave[v] < chave[u])) u = v;
        inMST[u] = true;
        
        for (int v = 0; v < n; v++) {
            if (grafo[u][v] != 0 && !inMST[v] && grafo[u][v] < chave[v]) {
                chave[v] = grafo[u][v];
                pai[v] = u;
            }
        }
    }
}

Complexidade: O(V²) com array simples; O(E log V) com fila de prioridade

Aula 6 – Aplicações e Coloração de Grafos

Coloração de Grafos

Atribuir cores a vértices de forma que nenhum par de vértices adjacentes tenha a mesma cor, usando o mínimo de cores possível (número cromático χ(G)).

  • Grafos bipartidos: χ = 2 (se não vazio)
  • Grafos com ciclo ímpar: χ ≥ 3
  • Grafo completo Kn: χ = n
Teorema das 4 Cores: qualquer mapa planar pode ser colorido com no máximo 4 cores. Provado em 1976 com auxílio computacional (Appel e Haken).

Aplicação: Alocação de Registradores

Compiladores modelam a interferência entre variáveis como um grafo de interferência e usam coloração para alocar registradores de CPU — cada cor representa um registrador físico.

Fluxo em Redes (Ford-Fulkerson)

Em um dígrafo com capacidades nas arestas, o fluxo máximo da fonte ao sumidouro é determinado pelo corte mínimo (Teorema Max-Flow Min-Cut).

// Algoritmo de Ford-Fulkerson (BFS = Edmonds-Karp, O(VE²))
int fordFulkerson(int[][] cap, int s, int t, int n) {
    int[][] residual = new int[n][n];
    for (int u = 0; u < n; u++)
        for (int v = 0; v < n; v++) residual[u][v] = cap[u][v];
    
    int maxFlow = 0;
    int[] pai = new int[n];
    
    while (bfsAumentante(residual, s, t, n, pai)) {
        int fluxoCaminho = Integer.MAX_VALUE;
        for (int v = t; v != s; v = pai[v])
            fluxoCaminho = Math.min(fluxoCaminho, residual[pai[v]][v]);
        for (int v = t; v != s; v = pai[v]) {
            residual[pai[v]][v] -= fluxoCaminho;
            residual[v][pai[v]] += fluxoCaminho;
        }
        maxFlow += fluxoCaminho;
    }
    return maxFlow;
}

Ordenação Topológica

Para DAGs (grafos dirigidos acíclicos): ordenar vértices de forma que toda aresta u→v tenha u antes de v na ordenação. Usado em: make/build systems, resolução de dependências, planejamento de tarefas.

// Usando DFS
void topoSort(GrafoLista g, int v, boolean[] vis, Stack<Integer> pilha) {
    vis[v] = true;
    for (int u : g.vizinhos(v))
        if (!vis[u]) topoSort(g, u, vis, pilha);
    pilha.push(v);  // adiciona após explorar todos os descendentes
}

// Resultado: pop da pilha dá a ordenação topológica
